# 샘향 × 므우 테일즈런너 가족 모집 홈페이지

## 구성
- `index.html` : 메인 페이지
- `assets/saemhyang.png` : 샘향 이미지
- `assets/meu.png` : 므우 이미지
- `assets/blueming.mp3` : 배경음악 (IU - Blueming)

## 사용 방법
1. ZIP을 풀기
2. `index.html` 열기
3. 시작 화면에서 `음악과 함께 입장` 또는 `조용히 입장` 선택

## 주요 기능
- 시네마틱 시작 화면
- IU Blueming 배경음악 / 재생, 일시정지, 볼륨 조절
- 가족 적합도 테스트
- 오늘의 운세
- 지원 문구 자동 복사
- `asa` 입력 시 이스터에그
- 갤러리 라이트박스
- 모바일 반응형

## GitHub Pages 배포
이 폴더 내용을 GitHub 저장소 루트에 업로드한 뒤 GitHub Pages를 활성화하면 됩니다.
